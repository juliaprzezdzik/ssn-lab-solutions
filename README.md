# ssn-lab-solutions

Solutions to lab assignments for the **Artificial Neural Networks** course at AGH University of Science and Technology, spring semester 2026.

The course introduces the theory and practical implementation of modern neural network architectures, building up from classical feed-forward networks to state-of-the-art generative and language models. Each notebook is self-contained and was designed to run in Google Colab with GPU acceleration.

## Topics

The labs cover, among other things:

- **Feed-forward networks** — multilayer perceptrons, activation functions, weight initialization, backpropagation
- **Regularization techniques** — dropout, batch normalization, early stopping, weight decay
- **Convolutional neural networks** — image classification, feature extraction, transfer learning
- **Recurrent architectures** — vanilla RNNs, LSTM and GRU cells, sequence modelling and text generation
- **Transformers and attention** — self-attention, encoder/decoder architectures, language modelling
- **Generative models** — generative adversarial networks (GANs) for image synthesis
- **Large language models** — fine-tuning and inference with pre-trained LLMs

## Tech stack

- Python 3.12
- TensorFlow / Keras
- PyTorch (selected notebooks)
- Hugging Face Transformers
- NumPy, pandas, matplotlib

## Notes

Each notebook contains both the implementation and short commentary on the design choices, hyperparameters, and observed results. Auxiliary data files (`.csv`, `.txt`) used by the notebooks are committed alongside them in the repository root.
